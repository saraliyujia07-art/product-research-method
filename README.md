## 内容

| 文件 | 讲什么 |
|---|---|
| `merged-framework.html` | **主文件**。以细化版六步SOP为骨架补入五处缺失件，每一步写清「做什么／补了什么／要你提供什么／自动化多少」，含开工前必须给的五项、两件要提前启动的长周期事、中途待办与缺失后果 |
| `index.html` | 两套方法的步骤级对照：哪些能互相替代、哪些不能 |
| `collection-checklist.html` | 字段级数据采集清单：8项数据的字段、来源、数量、交付格式与验收标准 |

三个页面底部互相有链接。都支持直接打印成 PDF（按章节自动分页）。
